    # I. Mục tiêu bài học

    ## 1. Về kiến thức

    - Nắm các toán tử `+ - * / // % **`.
- Hiểu thứ tự ưu tiên phép toán.
- Biết dùng ngoặc để biểu thức rõ ràng.

    ## 2. Về kỹ năng

    - Viết được chương trình Python đúng cú pháp.
    - Áp dụng được nội dung bài học vào bài toán nhập môn.
    - Trình bày lời giải rõ ràng theo hướng giáo án.

    ## 3. Về tư duy

    - Biết xác định Input, Xử lý và Output.
    - Biết kiểm tra công thức trước khi code.

    ---

    # II. Lý thuyết

    ## 1. Các phép toán

`/` là chia thực, `//` là chia nguyên, `%` là chia dư, `**` là lũy thừa.

## 2. Thứ tự ưu tiên

Ngoặc → lũy thừa → nhân/chia → cộng/trừ.

## 3. Viết công thức

Công thức toán nên được viết đầy đủ dấu ngoặc để tránh hiểu sai.

    ---

    # III. Ví dụ minh họa

    ## 1. Chu vi hình chữ nhật

```python
a = int(input())
b = int(input())
p = 2 * (a + b)
print(p)
```

## 2. Chia nguyên và chia dư

```python
a = int(input())
b = int(input())
print(a // b)
print(a % b)
```

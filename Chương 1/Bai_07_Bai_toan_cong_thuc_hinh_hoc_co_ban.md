    # II. Lý thuyết

    ## 1. Hình vuông

$P = 4a$, $S = a^2$.

## 2. Hình chữ nhật

$P = 2(a+b)$, $S = ab$.

## 3. Tam giác vuông và hình tròn

$S = \frac{ab}{2}$; $S_{tron} = 3.14r^2$.

    ---

    # III. Ví dụ minh họa

    ## 1. Hình chữ nhật

```python
a = int(input())
b = int(input())
print(2 * (a + b))
print(a * b)
```

## 2. Hình tròn

```python
r = float(input())
print(f"{2 * 3.14 * r:.2f}")
print(f"{3.14 * r * r:.2f}")
```
